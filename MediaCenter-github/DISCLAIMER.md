# Disclaimer - Media Center Beta 1.1

Read before downloading.

Media Center Beta 1.1 is early software, provided free, "as is", with no warranty of any kind.

- Beta status. The core works, but bugs are possible, crashes are possible, and features can change or be removed in the next version.
- Back up music and movies before use. The app only reads media files, except for one button that writes tags into M4A files, and only on explicit action. Backups are still recommended for anything important.
- Not notarized. This beta has not been checked by Apple. Testing included copying the DMG to a second Mac via USB stick, where it opened with no warning. A warning on some other Macs is still possible. If a warning appears, right-click the app, choose Open, then choose Open again. Download only from the official GitHub Releases page.
- Formats. Some files (MKV, AVI, WMV, MPG, and others) are listed but cannot play, because Apple ships no decoder for those formats. See the README for the full list.
- Online lookups. To fill in missing song info, artwork, and lyrics, the app contacts MusicBrainz, iTunes, and LRCLIB. No account is needed. Only the song details needed for the lookup are sent.
- No support promise. Issues are read, but no fix date is promised for any one bug.
- Use at own risk. By downloading and running Media Center, the downloader accepts that the copyright holder is not responsible for loss of data or damage, to the extent allowed by law.

Problems can be reported in GitHub Issues. That is how the beta improves.
