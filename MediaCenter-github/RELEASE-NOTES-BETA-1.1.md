# Media Center Beta 1.1

Download: `MediaCenter-1.1.dmg` below. Open it, drag Media Center into Applications.

Beta 1.1 is an early version. The core works. Bugs can be reported in Issues.

What it does: one free library for music and movies on Mac. Automatic song info, artwork, and karaoke lyrics, movie captions, playlists, AirPlay. No subscription, no account.

Plays: MP3, M4A, AAC, Apple Lossless, FLAC, WAV, AIFF, CAF, MP2, M4B; MP4, M4V, MOV, 3GP.
Listed but cannot play: MKV, AVI, WMV, MPG, and others. Apple ships no decoder for those formats.

Read the disclaimer (DISCLAIMER.md in the repo) before downloading. In short: beta, back up files first. Tested by copying the DMG to a second Mac via USB stick, where it opened with no warning. This build is not notarized, so a warning on some other Macs is still possible. If a warning appears, right-click the app, choose Open, then choose Open again.

Source code is in this repo. Build in Xcode: open MediaCenter.xcodeproj, Cmd+B.
